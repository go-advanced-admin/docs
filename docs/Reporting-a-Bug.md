# Reporting a Bug

If you encounter a problem while using Go Advanced Admin, let us know so we can fix it quickly. This page walks you
through the information we need and the best place to submit it.

## Before You Report

- **Check existing issues:** Look through [open GitHub issues](https://github.com/go-advanced-admin/admin/issues) to see
  if someone has already reported the problem.
- **Reproduce the bug:** Confirm the issue is repeatable and not a one-off glitch. If possible, test on the latest
  release.
- **Collect details:** Gather environment information (Go version, operating system, database, integrations) and any
  relevant logs or screenshots.

## Open a GitHub Issue

1. Go to the [bug report template](https://github.com/go-advanced-admin/admin/issues/new?template=bug_report.md).
2. Provide a concise, descriptive title.
3. Fill out each section of the template:
   - **Summary:** Describe what is happening and what you expected instead.
   - **Steps to reproduce:** List clear, step-by-step instructions. Include any configuration files or code snippets
     needed to trigger the bug.
   - **Environment:** Mention your Go version, OS, database, and the admin integrations involved.
   - **Logs or screenshots:** Paste relevant stack traces, error messages, or link to screenshots.
4. Submit the issue so the maintainers and community members can help investigate.

## Follow Up

- Be responsive to questions—maintainers may need clarification to reproduce the bug.
- If you find additional details, add them as comments to the issue.
- Once the bug is fixed, verify the resolution and close the issue (or let us know so we can close it for you).

By sharing thorough reports you help us ship fixes faster and improve the experience for everyone.
